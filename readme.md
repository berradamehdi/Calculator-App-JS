A sleek and responsive calculator web application built with HTML, CSS, and JavaScript, featuring a modern user interface and smooth arithmetic operations.

## ✨ Features

- **Standard Operations:** Addition, subtraction, multiplication, and division.
- **Clear & Delete:** Clear the entire screen (`AC`) or delete the last digit (`DEL`).
- **Modern UI:** Clean layout with ergonomic spacing and smooth button active states.
- **Responsive Design:** Fully adaptable to mobile and desktop screens.

---

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3 (Flexbox, Grid, Custom Properties)
- **Logic:** Vanilla JavaScript (DOM Manipulation, Event Handling)
